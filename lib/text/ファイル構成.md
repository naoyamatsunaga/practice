---

### 主なファイルの役割

| パス | 役割 |
|------|------|
| `lib/main.dart` | 起動・`ProviderScope`・`databaseProvider` の override |
| `lib/app_router.dart` | `GoRouter` とボトムナビのルート定義 |
| `lib/core/utils/reset_time.dart` | リセット時刻まわりの日付計算（純関数） |
| `lib/models/task.dart` / `preset.dart` | アプリ内のデータ型（`TaskModel` / `PresetModel`） |
| `lib/models/data/database.dart` | Drift の DB・テーブル・CRUD |
| `lib/models/repositories/*.dart` | ViewModel 向けのデータ操作窓口 |
| `lib/view_models/*.dart` | Riverpod Provider と画面ロジック |
| `lib/views/pages/*.dart` | 各タブ画面 |
| `lib/views/dialogs/*.dart` | ダイアログ UI |
| `lib/views/widgets/*.dart` | 再利用ウィジェット |

---

### 新規追加時の置き場所（クイック参照）

- 画面 → `lib/views/pages/`
- ダイアログ → `lib/views/dialogs/`
- 共通 UI 部品 → `lib/views/widgets/`
- 画面の状態・操作 → `lib/view_models/`
- DB テーブル・マイグレーション → `lib/models/data/database.dart`
- データ取得 API → `lib/models/repositories/`
- 複数画面で使う純粋関数 → `lib/core/utils/`
- ルート追加 → `lib/app_router.dart`

---

### 補足

- `database.g.dart` は `build_runner` の生成物。手動編集しない。
- 旧構成（`lib/home.dart`、`lib/providers/states/` など）は廃止済み。
